# Modern Portfolio

A modern portfolio / link hub built with Next.js, TypeScript and Tailwind CSS.

## Overview

This project was created as a personal portfolio site to showcase:

- Web applications
- Creative archives
- Personal projects
- UI / visual design

The design direction is inspired by:

- Vercel
- Linear
- Minimal SaaS UI
- Dark modern portfolios

---

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vercel

---

## Features

- Responsive modern UI
- Project cards
- Dynamic project detail pages
- Smooth scrolling
- Framer Motion animations
- Dark minimal design

---

## Projects Included

- Outfit Archive
- Poem Archive
- Link Hub

---

## Getting Started

```bash
npm install
npm run dev
````

Open:

```txt
http://localhost:3000
```

## Deployment
